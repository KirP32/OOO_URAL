# Деталь: поиск автозапчастей

## Как запустить

Нужен Node.js 22.12 или новее.

```bash
git clone git@github.com:KirP32/OOO_URAL.git
cd OOO_URAL
npm ci
npm run dev
```

Откройте адрес из терминала.

## Как использовать

1. Введите ключ покупателя Favorit Parts и нажмите «Использовать ключ».
2. Введите артикул: поиск начнётся автоматически. Можно нажать «Найти».
3. Выберите производителя.
4. В таблице появятся предложения и аналоги с ценами и остатками на складах.

Без API-ключа поиск не работает. После перезагрузки страницы ключ нужно ввести заново.

[Документация API Favorit Parts](https://lk.favorit-parts.ru/static/wsprice.pdf)

## Тесты и сборка

```bash
npm test
npm run build
```

Готовая сборка: папка `dist`. Локальный просмотр сборки: `npm run preview`.
